# Contribuir com o SPC Lab

1. Descreva o problema com dados sintéticos, carta escolhida, tamanho dos subgrupos e valores esperados.
2. Execute `npm run check` e `npm test` antes de abrir uma alteração.
3. Para mudanças estatísticas, adicione uma referência independente e um teste que confirme o resultado. Evite testes que apenas repitam a implementação.
4. Preserve as distinções entre limite de controle e especificação, estabilidade e capacidade, desvio dentro e desvio global.
5. Documente métodos fora do escopo e qualquer mudança de premissa ou de arredondamento.
6. Confira acessibilidade e navegação do fluxo alterado.

Não inclua dados industriais confidenciais, backups pessoais, tokens, credenciais ou arquivos de configuração da hospedagem. Não altere a audiência do site nem habilite implantação pública como parte de uma contribuição de código.

O projeto não possui licença aberta de redistribuição definida. As contribuições dependem de acesso e aceite do proprietário.
